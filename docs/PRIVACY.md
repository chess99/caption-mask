# Caption Mask 隐私政策 / Privacy Policy

最后更新：2026-08-27

## 中文

Caption Mask 不收集、记录、上传、共享或出售任何个人数据、网页内容或浏览记录。

当用户主动点击扩展图标或按下快捷键时，扩展会临时在当前标签页中运行随扩展打包的代码，以显示字幕遮罩。扩展不会在后台持续读取网页，也不会把网页内容发送到任何服务器。

扩展仅使用 `chrome.storage.local` 在用户设备上保存遮罩的位置、尺寸、颜色和透明度。升级旧版本时，扩展可能读取当前网站本地存储中名为 `caption-mask-sizing` 的旧设置并迁移到扩展本地存储；它不会读取其他键。保存的数据不会离开用户设备，卸载扩展后可由 Chrome 清除。

Caption Mask 不使用分析服务、广告、追踪器或远程托管代码。源代码公开在 <https://github.com/chess99/caption-mask>。如有隐私问题，请通过 <https://github.com/chess99/caption-mask/issues> 联系维护者。

## English

Caption Mask does not collect, log, upload, share, or sell personal data, page content, or browsing history.

When the user explicitly clicks the extension action or invokes its keyboard shortcut, the extension temporarily runs bundled code in the active tab to display the caption mask. It does not continuously read pages in the background and does not send page content to any server.

The extension uses `chrome.storage.local` only to store the mask position, size, color, and opacity on the user's device. When upgrading from an older version, it may read the legacy `caption-mask-sizing` setting from the current site's local storage and migrate that setting to extension storage; it does not read any other key. Stored settings never leave the device and may be removed by Chrome when the extension is uninstalled.

Caption Mask uses no analytics, advertising, trackers, or remotely hosted code. Its source code is available at <https://github.com/chess99/caption-mask>. Privacy questions may be submitted at <https://github.com/chess99/caption-mask/issues>.
